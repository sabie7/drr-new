# DRR Chat — النسخة المصدرية الموحّدة

**المكدس:** Vue 3.5 · Tailwind CSS 4 · Vite 8 · Node 20+ · Socket.IO 4.7.5

مستودع **الكود المصدري المقسّم احترافياً** — ملفات البناء المضغوطة لا تُخزَّن هنا،
تولَّد بأمر واحد لكل مكوّن.

---

## خريطة المستودع

| المسار | الوصف | دليل الصيانة |
|--------|-------|--------------|
| `client/js/main-parts/` | دردشة العملاء — 28 جزءاً موضوعياً | MANIFEST.md داخل المجلد |
| `client/js/*.js` + `client/css/` | وحدات العميل الحية والتنسيقات | — |
| `src/server-parts/` | السيرفر — 16 جزءاً موضوعياً | MANIFEST.md داخل المجلد |
| `cp-app/` | لوحة التحكم (Vue 3.5 + Tailwind 4) مصدر كامل | — |
| `cp-dist/` · `dist/` | مخرجات البناء الجاهزة للنشر (آخر إصدار) | — |
| `assets/flag/` | أعلام الدول | — |
| `client/uploads/site/` | هوية الموقع (فافيكون/بانر/أفاتار) | — |

> ملاحظة: وسائط المستخدمين الثقيلة غير مخزنة هنا — تُدار من الاستضافة مباشرة.

---

## البناء

```bash
npm install              # جذر المشروع
npm run build            # يبني: السيرفر + حزمة الدردشة
npm run build:panel      # لوحة التحكم Vue (تخرج cp-dist)
```

| الأمر | الناتج |
|---|---|
| build:server | dist-server/server.<ver>.js + Source Map |
| build:chat   | client/dist/chat-main.<ver>.js ويطبع VERSION_TOKEN |
| build:panel  | cp-dist/ كاملاً |

## النشر

1. ارفع مخرجات البناء إلى نفس مساراتها على الاستضافة.
2. حدّث أرقام v= في landing.js و index.html عند تغير أي hash.
3. أعد التشغيل بشكل إجباري (hard restart) — القاعدة الذهبية.

## قواعد الصيانة

- أجزاء main-parts و server-parts مرتبة: لا تعيد ترتيبها ولا تغيّر أرقامها.
- أي تعديل على client/js يتطلب رفع رقم الإصدار، وإلا بقي المستخدمون على النسخة المخزنة.
- الإيموجي يحتاج حقل type في البيانات (يضيفه السيرفر تلقائياً الآن).
